# YOUR.DEV — iOS Developer Portfolio

A personal portfolio site with an AI-powered chatbot assistant.

---

## 🗂 Project Structure

```
portfolio-site/
├── index.html            ← Markup only
├── css/
│   └── styles.css        ← All custom styles
├── js/
│   ├── tailwind-config.js ← Tailwind CDN theme config
│   └── main.js           ← All behaviour (chatbot, cursor, animations, forms)
├── server.js             ← Local static server (npm start → :3001)
└── README.md             ← Project overview
```

---

## 🚀 Deployment

| Platform | Method | Free? |
|---|---|---|
| GitHub Pages | Push to repo → Settings → Pages → Deploy from main | ✅ |
| Netlify | Drag & drop the folder at netlify.com/drop | ✅ |
| Vercel | `vercel deploy` from this folder | ✅ |
